# 赛题一与江城验真实现映射

依据：[汉客松 S1 & ETH Wuhan 2026 选手手册](https://tokenark.feishu.cn/docx/Vn3hdD7s6okrftx9583cYgganMg)「Agent 公共信誉与服务验收」。本表是产品对照说明，不是官方评分表或逐字摘录。官方探索允许从服务探测、验收、履约历史、聚合与抗刷分等方向切入；登记本身不等同于能力。

| 方向与痛点 | 本项目交付 | 当前状态 | 检查方式 |
| --- | --- | --- | --- |
| 服务是否实际可用 | 固定 PublicNode 只读探测与响应耗时 | 已实现并有真实读取样本 | `POST /api/probe`，查看来源、时间、检查与拒绝原因 |
| 服务交付如何验收 | 版本化约定，链ID、时效、完整性、关联、耗时检查 | 已实现 | 3/3 回执与关联一致；错链、过期、缺项不能选中 |
| 服务如何选择 | 顺序遍历启用目录，首个全部通过者才被选择 | 已实现选择机制；当前仅一个启用提供商 | 失败结果 `selected_provider=null`；不宣传已实现可靠多源冗余 |

| 重复运行影响评价 | 同服务、快照、规则及判定/失败项去重；无交付错误按五分钟桶去重，样本分母可见 | 已实现局部去重 | 相同结果重复不增加总数；通过变过期或超时仍留档；通过+拒绝=总数 |
| 共享证据和复核 | 下载、导入、摘要重算、规则重放 | 已实现 | 修改检查结果后即使重算哈希，重放仍拒绝 |
| 不合格服务如何展示 | 健康、过期、缺回执的固定试验 | 合成示例 | 示例运行前后真实账本样本数不变 |
| 跨主体公共信誉、身份和抗女巫 | 未连接公共身份、独立验证者、信誉治理与链上登记 | 未实现；后续方向 | 页面和材料不将本实例通过率写成全网信誉 |

## 可量化约定

链 ID 必须为 1；RPC 返回 finalized 标签；检查点年龄在 −30 至 1800 秒。最多抽样前3笔交易，每笔回执的交易哈希、区块哈希与高度必须一致。采集耗时上限16000 ms。错误服务的选中次数、合成示例入账数均须为0。规则是项目演示约定，不构成官方标准或提供商商业 SLA。

本地真实样本及自动化证据见 `tests/live-probe-result.json` 与 `tests/test_backend.py`。生产网页与资源的部署目标为 <https://wutiantian.cn/agent-trust/>，本文件制作时**部署待核验**。

## 尚不能由当前证据得出的结论

一次成功探测不能证明长期稳定；自托管观测不等于独立评价；去重不等于抗女巫；摘要一致不等于来源真实。后续若扩展公共信誉，需要真实身份绑定、评价者治理、跨实例复核和争议处理，分别提供可验证证据。
